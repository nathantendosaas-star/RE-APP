Why Gemini 2.5 Flash Lite Is The Right Call
It's a lightweight reasoning model optimized for ultra-low latency and cost efficiency, with a 1,048,576 token context window. For your use case — generating listing descriptions and captions — you don't need a heavy model. Flash Lite will crush it at a fraction of the cost.
Cost math per generation: Your prompt + property details ≈ ~800 input tokens. Output (description + 5 captions + email) ≈ ~1,200 output tokens.
* Input cost: 800 × $0.0000001 = $0.00008
* Output cost: 1,200 × $0.0000004 = $0.00048
* Total per generation: ~$0.00056 — less than 1/10th of a cent
At 1,000 generations/month you spend $0.56 in API costs. Even at 50,000 generations you're paying $28. Your $29/month tier alone covers 50,000 generations. Pure profit margin.
Flash Lite also gives you 1,000 requests per day on the free tier alone — meaning you can run your entire beta testing phase for free before spending a single dollar.

import { GoogleGenerativeAI } from "@google/generative-ai";


const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY!);


export async function POST(req: Request) {
  const { listing } = await req.json();


  // 1. Check generation limit before calling API
  // (query Supabase here — skip for brevity)


  const model = genAI.getGenerativeModel({
    model: "gemini-2.5-flash-lite",   // the model string
    generationConfig: {
      responseMimeType: "application/json",  // forces clean JSON back
    },
  });


  const prompt = `
You are an expert real estate copywriter with 15 years of experience.


PROPERTY DETAILS:
- Address: ${listing.address}
- Price: $${listing.price.toLocaleString()}
- Bedrooms: ${listing.bedrooms} | Bathrooms: ${listing.bathrooms}
- Property Type: ${listing.propertyType}
- Key Features: ${listing.feature1}, ${listing.feature2}, ${listing.feature3}
- Target Buyer: ${listing.targetBuyer}
- Tone: ${listing.tone}


Generate marketing content and return ONLY a valid JSON object in this exact structure:
{
  "listing_description": "150-250 word MLS-ready listing description. Compelling, specific, no clichés.",
  "captions": {
    "instagram_1": "Caption with relevant emojis and 5-8 hashtags. Max 2,200 chars.",
    "instagram_2": "Different angle from instagram_1. Highlight a different feature.",
    "facebook": "Conversational, slightly longer, great for sharing. No hashtags.",
    "linkedin": "Professional tone targeting investors or relocating professionals.",
    "twitter": "Punchy and attention-grabbing. MUST be under 280 characters including spaces."
  },
  "email": {
    "subject": "Compelling email subject line under 60 characters",
    "body": "Full email for agent to send to their buyers list. 150-200 words. Warm, professional. End with clear call to action."
  }
}


Return ONLY the JSON. No explanations. No markdown. No backticks.
`;


  const result = await model.generateContent(prompt);
  const text = result.response.text();
  const data = JSON.parse(text);


  // 2. Save to Supabase + increment generations_used
  // 3. Generate mini_site_slug with nanoid
  // 4. Return to frontend


  return Response.json({ success: true, content: data });
}
