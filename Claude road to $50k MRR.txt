### What You Build (MVP — 3–4 weeks)


A simple web app where an agent:
1. Enters property address, bedrooms, price, 3 key features
2. Uploads 1–2 photos (optional)
3. Hits **Generate**
4. Gets: listing description + 5 social captions + buyer email + shareable link


**Your stack:** Next.js or vibe-coded frontend → Claude API for generation → Vercel (you already know this) → Stripe via your friend.
